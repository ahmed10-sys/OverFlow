DocIndexer CLI

High-throughput local document chunking, semantic embedding, and Qdrant vector index synchronization pipeline with incremental file watcher support.

Primary Purpose

DocIndexer monitors multi-format documentation trees (Markdown, PDF, HTML), extracts semantic sections, computes dense embeddings, and synchronizes vector indices in real time without duplicating unchanged documents.

Control Flow & Architecture

The CLI entrypoint invokes watcher.py to detect file changes. Modified files pass to parser.py which extracts semantic chunks and metadata. Embeddings are computed in batches via embedder.py and ingested into Qdrant using client upsert calls. Telemetry and sync state are persisted to an embedded SQLite state store.

Invariants & Edge Cases

Embedding failures trigger exponential backoff retry. Unparseable binary documents are quarantined to a dead-letter manifest rather than halting the sync loop. Index updates are strictly idempotent based on SHA-256 document content hashes.
